##TOPIC(help,label="pmaple") maplev:-pmaple
##HALFLINE brief description of the pmaple binary
##
##DESCRIPTION
##- **pmaple** is binary produced with "OpenMaple" that provides
##  access to the Maple engine from Emacs.  It can be used to simulate
##  the command line version of Maple, serve help pages, and display
##  procedures and modules stored in Maple archives.
##
##- For help on **pmaple**,
##  open the ~maplev~ info page and goto the ~Maple~ node.
##
##SEEALSO
##- "OpenMaple"
